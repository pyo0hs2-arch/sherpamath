홈페이지는 3개의 시스템이 연결되어 있습니다.

  ┌─────────────────┐
  │   가비아         │  도메인 (sherpamath.co.kr)
  │  (도메인 소유)   │  - 원장님 명의·계정
  └────────┬────────┘
           │ DNS 연결
           ▼
  ┌─────────────────┐
  │   Vercel         │  사이트 호스팅 (자동)
  │  (사이트 서버)   │  - 코드만 GitHub에 올리면 자동 배포
  └────────┬────────┘
           │ 코드 가져옴
           ▼
  ┌─────────────────┐
  │   GitHub         │  코드·사진 저장소
  │  (소스 보관)     │  - 여기서 수정하면 즉시 사이트 반영
  └─────────────────┘

★ 일상 관리는 GitHub만 건드리시면 됩니다.
  - 글·사진 수정 = GitHub에서 파일 편집
  - 1~2분 후 Vercel이 자동으로 사이트 업데이트
  - 가비아·도메인은 손댈 일 거의 없음

PART 2.  권한 받기 - 최초 1회만 진행
============================================================

▼ Step 1. GitHub 계정 만들기

   1) https://github.com 접속

   2) 우측 상단 [Sign up] 클릭

   3) 이메일·비밀번호·아이디 입력
      - 아이디: 영문/숫자, 예 sherpamath-edu
      - 이메일: 학원 메일 사용 권장
      - 비밀번호: 안전하게

   4) 가입 완료 후 메일 인증

   ※ GitHub 가입 시 본인 인증 등 절차 없음.
     이메일과 비밀번호만 있으면 됩니다.

   ※ 가입 후 GitHub 아이디를 저(회원님)에게 알려주세요.

   ────────────────────────────────────────

▼ Step 2. Collaborator(공동 관리자) 초대 받기

   회원님(저)이 원장님 아이디로 초대장을 보냅니다.

   1) 초대 메일을 GitHub 가입 이메일로 받습니다
      제목: "@회원님_아이디 invited you to ..."

   2) 메일 안의 [View invitation] 버튼 클릭

   3) [Accept invitation] 클릭

   4) 이제 원장님도 sherpamath 레포에 들어갈 수 있습니다
      주소: https://github.com/pyo0hs2-arch/sherpamath

   ────────────────────────────────────────

▼ Step 3. Vercel 권한 (선택 사항)

   GitHub 권한만 있어도 사이트는 자동 반영됩니다.
   Vercel 권한은 배포 상태 모니터링용이라 굳이 필요 없음.

   필요하시면 추후 안내.

PART 3.  일상 관리 ① — 텍스트 수정
============================================================

가장 자주 하실 작업입니다. GitHub 웹에서 바로 편집 가능.

▼ 기본 절차 (모든 수정 공통)

   1) https://github.com/pyo0hs2-arch/sherpamath 접속

   2) 파일 목록에서 [index.html] 클릭

   3) 우측 상단 ✏️ 연필 아이콘 (Edit this file) 클릭

   4) Ctrl+F (찾기) 로 수정할 내용 검색
      예: "효성여고 장○○" 검색하면 그 부분으로 이동

   5) 텍스트 수정

   6) 우측 상단 녹색 [Commit changes...] 버튼 클릭

   7) 팝업에서 다시 [Commit changes] 클릭

   8) 1~2분 후 https://www.sherpamath.co.kr 새로고침 (Ctrl+F5)

   ────────────────────────────────────────

▼ 자주 수정하는 부분 위치

   [ 원장님 인사말 / 학원 철학 ]
     Ctrl+F 검색: "수학의 성과는 정확한 수준"

   [ 강사 이력 ]
     Ctrl+F 검색: "최재영" 또는 "윤기원" 또는 "박은비"
     - 학력·경력 줄 추가/수정 가능

   [ 합격 사례 (효성여고 장OO 등 3장) ]
     Ctrl+F 검색: "효성여고" 또는 "영남고"

   [ 진학 대학 목록 ]
     Ctrl+F 검색: "MAJOR ADMISSIONS"
     - <span>대학명</span> 형식으로 추가

   [ 학부모 후기 6개 ]
     Ctrl+F 검색: "rev-card"

   [ 운영시간 ]
     Ctrl+F 검색: "16:30 – 22:00"

   [ 전화번호 / 카톡 / 인스타 / 블로그 ]
     Ctrl+F 검색: "053-633-4221" 또는 "sherpamath"

   [ 교습비 표 ]
     Ctrl+F 검색: "고등 수학특강" 또는 "월 교습비"
     - 금액 수정 시 형식 그대로 (예: 550,000원)

   ────────────────────────────────────────

▼ 텍스트 수정 예시 1: 전화번호 변경

   [Before]
   <a href="tel:053-633-4221" class="top-cta">053-633-4221</a>

   [After] - 전화번호만 두 곳 다 바꿈
   <a href="tel:053-XXX-XXXX" class="top-cta">053-XXX-XXXX</a>

   ※ "tel:" 뒤의 숫자에는 - 빼고 입력
     예: tel:053XXXXXXX

   ────────────────────────────────────────

▼ 텍스트 수정 예시 2: 운영시간 변경

   [Before]
   <li>월·화·목·금 16:30 – 22:00</li>

   [After]
   <li>월·화·목·금 17:00 – 22:00</li>

   ※ <li>와 </li> 사이의 글자만 수정.
     <li>, </li> 같은 꺽쇠 표시는 절대 지우지 마세요.

PART 4.  일상 관리 ② — 후기·합격사례 추가
============================================================

▼ 학부모 후기 추가하기

   1) GitHub index.html 편집 모드 진입 (PART 3 절차)

   2) Ctrl+F 검색: "rev-card"

   3) 다음과 같은 형태의 블록 6개가 보입니다:

      <div class="rev-card">
        <p class="rev-text">후기 내용...</p>
        <div class="rev-author">재원생 학부모</div>
      </div>

   4) 그 중 하나를 통째로 복사하여 바로 아래에 붙여넣기

   5) 후기 내용과 작성자만 수정

   6) Commit changes

   ────────────────────────────────────────

▼ 합격 사례 카드 추가/수정

   현재 3장 있습니다. 추가하려면:

   1) Ctrl+F 검색: "효성여고 장○○"

   2) 다음 블록을 찾아 통째로 복사:

      <div class="ach-card reveal">
        <span class="tag">성적 향상</span>
        <div class="title">효성여고 장○○</div>
        <p style="...">설명 텍스트...</p>
        <div class="ba-bar"><div class="ba-fill" style="--target:0%"></div></div>
        <div class="ba-labels"><span>3등급</span><span style="color:var(--gold)">1등급 ↑</span></div>
        <div class="change">3등급 → 수능 1등급</div>
      </div>

   3) </div> 다음에 붙여넣기

   4) 내용 수정:
      - <span class="tag">성적 향상</span> ← "진학 성공"으로도 가능
      - <div class="title">학교명 학생○○</div>
      - <p>설명</p>
      - <ba-fill style="--target:0%"> ← 막대 채울 비율 (0%=가득, 50%=절반)
      - <ba-labels> ← 시작/끝 글자
      - <change>최종 결과 문구</change>

PART 5.  일상 관리 ③ — 사진 교체
============================================================

사진 교체는 텍스트보다 복잡합니다.
원장님이 직접 하기 어려우시면 회원님께 카톡으로 요청하세요.

▼ 직접 교체하기 (도전해보실 분만)

   현재 사진 목록 (img 폴더):

   ┌────────────────────────┬───────────────────────────┐
   │ 파일명                  │ 사용 위치                  │
   ├────────────────────────┼───────────────────────────┤
   │ interior-classroom1.jpg │ 메인 첫 화면 배경          │
   │ philo-1.jpg            │ 학원 철학 위쪽 사진        │
   │ philo-2.jpg            │ 학원 철학 아래쪽 사진      │
   │ sys-planner.jpg        │ 시스템 01 (학업 일지)      │
   │ systems.jpg            │ 시스템 02 (4분할 노트)     │
   │ sys-test.jpg           │ 시스템 03 (주간 TEST)      │
   │ class1.jpg             │ DIRECTOR 최재영 원장       │
   │ teacher-yoon.jpg       │ DIRECTOR 윤기원 선생님     │
   │ teacher-park.jpg       │ DIRECTOR 박은비 선생님     │
   └────────────────────────┴───────────────────────────┘

   ────────────────────────────────────────

   [교체 절차]

   1) 새 사진을 PC에 저장
      - 가로형 권장 (4:3 또는 16:9)
      - 1MB 이하 권장 (너무 크면 사이트 느려짐)
      - 파일명은 영문으로 (예: new-photo.jpg)

   2) GitHub 레포 → img 폴더 클릭
      https://github.com/pyo0hs2-arch/sherpamath/tree/main/img

   3) 교체할 파일명 클릭 (예: teacher-yoon.jpg)

   4) 우측 상단 🗑️ 휴지통 아이콘 → 삭제 → Commit

   5) img 폴더로 돌아가서 [Add file] → [Upload files]

   6) 새 사진을 끌어다 놓기

   7) ⚠️ 중요 - 파일명을 정확히 원래 이름으로 바꿈
      예: 새 사진을 teacher-yoon.jpg 로 이름 변경 후 업로드

   8) Commit changes

   9) 1~2분 후 사이트 새로고침 (Ctrl+F5)

   ────────────────────────────────────────

▼ 회원님께 사진 교체 요청하는 방법 (권장)

   카톡으로 다음 두 가지 전달:

   1) 새 사진 파일
   2) 어디에 들어갈 사진인지
      예: "이거 윤기원 선생님 사진으로 교체해주세요"

   회원님이 압축·이름변경·업로드까지 처리합니다.
   처리 시간: 평균 30분 이내

PART 6.  안전장치 — 실수했을 때 되돌리기
============================================================

GitHub는 모든 변경 내역을 자동 저장합니다.
실수해도 언제든 이전 버전으로 되돌릴 수 있어요.

▼ 방법 1. Commit 히스토리에서 되돌리기

   1) GitHub 레포 메인 화면

   2) 우측 [Commits] 또는 시계 모양 아이콘 클릭
      (영어로 보면 "X commits" 라고 적힌 부분)

   3) 변경 내역 목록이 시간순으로 나옴

   4) 되돌리고 싶은 시점의 commit 클릭

   5) 우측 상단 [...] → [Revert] 또는
      URL을 복사해서 그 시점으로 복원 가능

   ────────────────────────────────────────

▼ 방법 2. 막혔을 때 (가장 안전한 방법)

   카톡으로 "OOO 수정하다가 이상해졌어요" 라고
   회원님께 알려주시면 30분 내 복구해드립니다.

   ⚠️ 절대 패닉하지 마세요. 사이트는 어떤 상황에서도
     이전 버전으로 100% 복구 가능합니다.

PART 7.  자주 묻는 질문
============================================================

Q1. 수정했는데 사이트가 안 바뀌어요.
A.  - 2분 더 기다리기 (Vercel 자동 배포 중)
    - 강력 새로고침 (Ctrl + F5)
    - 시크릿 모드(InPrivate)로 접속해보기

Q2. Commit 메시지에 뭐라고 적어야 하나요?
A.  "후기 추가", "전화번호 변경" 같이 간단히 한국어로 적으셔도 됩니다.
    영어로 적을 필요 없어요.

Q3. 코드가 너무 길어서 무서워요.
A.  필요한 부분만 Ctrl+F로 검색해서 그 부분만 수정하시면 됩니다.
    전체를 이해할 필요 없어요.

Q4. 모바일에서도 수정 가능한가요?
A.  GitHub 앱(App Store/Play Store)으로 가능하지만 PC가 훨씬 편합니다.
    가능하면 PC에서 작업하세요.

Q5. 다른 사람이 함부로 수정할 수 있나요?
A.  아니요. Collaborator로 초대받은 사람만 수정 가능합니다.
    현재: 원장님 + 회원님 2명만 가능.

Q6. 수정한 게 다른 사람에게 보이려면 시간이 얼마나 걸리나요?
A.  Commit 후 1~2분이면 모든 방문자에게 즉시 반영됩니다.

Q7. HTML 코드가 깨졌어요. 어떡하죠?
A.  카톡으로 즉시 알려주세요. 가장 마지막 정상 버전으로 복구해드립니다.

Q8. 새 페이지 추가 (예: 입학 절차 페이지) 도 가능한가요?
A.  가능하지만 복잡합니다. 회원님께 요청하시는 게 낫습니다.

Q9. 도메인 만료될 때는 어떻게 하나요?
A.  가비아에서 매년 결제 안내 메일이 옵니다.
    원장님 가비아 계정에서 직접 연장하시면 됩니다.
    GitHub·Vercel은 무료라 만료 없음.

Q10. 카카오톡 채널 URL이 바뀌면 어디서 수정하나요?
A.  Ctrl+F 검색: "pf.kakao.com"
     코드 안에 2~3곳 나옵니다. 모두 새 URL로 교체.
