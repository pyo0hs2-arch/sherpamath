CORE SYSTEM

셰르파의 3대 관리 시스템

단순 진도가 아니라, 학습의 전 과정을 관리합니다.

SYSTEM 01
학업 일지 관리

매주 원장과 담당 강사가 직접 플래너를 확인하여 학습 계획 이행 여부를 점검하고 올바른 학습 태도를 훈육합니다.

SYSTEM 02
4분할 노트 + 책 정리

셰르파 전용 4분할 노트를 제공하여 풀이 과정을 논리적으로 정리하고, 정기 교재 검사로 완벽한 책 정리를 추구합니다.

SYSTEM 03
주간 TEST + 오답 반복

주간테스트 → 첨삭 → 오답 유사 유형 재시험 → 재첨삭. 자체 프로그램으로 약점을 분석·보완합니다.
