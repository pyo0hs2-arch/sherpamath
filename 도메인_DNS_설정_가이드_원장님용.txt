============================================================
        셰르파 수학학원 도메인 연결 가이드
        (가비아 → Vercel DNS 설정)
============================================================

원장님, 도메인 구매 후 이 안내서대로 따라하시면 됩니다.
혼자 하기 어려우시면 카톡으로 막힌 화면 캡처 보내주세요.
실수해도 되돌릴 수 있으니 부담 없이 진행하세요.


============================================================
■ 시작하기 전에
============================================================

다음이 준비되어 있어야 합니다:

  □ 가비아에서 도메인 구매 완료
    (예: sherpamath.com)

  □ 가비아 아이디 / 비밀번호

  □ PC 또는 노트북 (스마트폰으로도 가능하지만 PC 권장)

  □ 시간 약 10~15분 (설정 자체는 5분, 확인까지 포함)

※ 도메인 연결 후 사이트가 새 주소로 뜨기까지
   최대 24시간 걸릴 수 있습니다. 보통은 30분~1시간 내.


============================================================
■ 입력해야 할 핵심 정보 (먼저 메모해두세요)
============================================================

가비아 DNS 설정 화면에서 아래 두 가지를 입력합니다.
이 값은 모든 학원이 동일하니 그대로 복사해서 쓰세요.

┌─────────────────────────────────────────────────────────┐
│  레코드 ①                                               │
│  ─────────────                                          │
│  타입(Type) : A                                         │
│  호스트(Host) : @                                       │
│  값/IP주소(Value) : 76.76.21.21                         │
│  TTL : 600 (또는 기본값 그대로)                         │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  레코드 ②                                               │
│  ─────────────                                          │
│  타입(Type) : CNAME                                     │
│  호스트(Host) : www                                     │
│  값(Value) : cname.vercel-dns.com                       │
│  TTL : 600 (또는 기본값 그대로)                         │
└─────────────────────────────────────────────────────────┘

★ 두 레코드 모두 빠짐없이 등록해야
  sherpamath.com 과 www.sherpamath.com 둘 다 작동합니다.


============================================================
■ STEP 1. 가비아 로그인
============================================================

  1) 인터넷 브라우저(크롬·엣지 등) 열기

  2) 주소창에 입력:
     https://www.gabia.com

  3) 우측 상단 [로그인] 클릭

  4) 아이디·비밀번호 입력 후 로그인


============================================================
■ STEP 2. My가비아 → 도메인 관리
============================================================

  1) 로그인 후 우측 상단 본인 이름 또는 [My가비아] 클릭

  2) 왼쪽 메뉴에서
     [서비스 관리] → [도메인 통합 관리툴]
     (또는 메인 화면에서 "도메인" 영역의 [관리] 버튼 클릭)

  3) 구매하신 도메인(예: sherpamath.com) 옆에
     [DNS 관리] 또는 [관리] 버튼 클릭

※ 가비아 화면이 종종 바뀝니다.
  메뉴 이름이 살짝 달라도 "도메인" 또는 "DNS" 라는 글자가
  들어간 메뉴를 찾으시면 됩니다.


============================================================
■ STEP 3. DNS 설정 화면 진입
============================================================

  1) 도메인 옆 [DNS 정보] 또는 [DNS 설정] 클릭

  2) 비슷한 표가 나타납니다 (예시):

     ┌────┬──────┬──────────────────┬──────┐
     │타입 │ 호스트│      값          │ TTL  │
     ├────┼──────┼──────────────────┼──────┤
     │ A  │  @   │ ...              │ 3600 │
     │ NS │  @   │ ns.gabia.co.kr   │ 3600 │
     └────┴──────┴──────────────────┴──────┘

  3) 기본으로 들어있는 가비아의 NS, MX, SOA 레코드 등은
     절대 삭제하지 마세요.
     (메일 보내고 받기, 도메인 작동에 필요)

  4) [레코드 추가] 또는 [+ 추가] 버튼을 찾으세요.


============================================================
■ STEP 4. 첫 번째 레코드 추가 (A 레코드)
============================================================

  [+ 레코드 추가] 클릭 후 다음과 같이 입력:

  ┌─────────────────────────────────┐
  │ 타입      : A                   │
  │ 호스트    : @                   │
  │ 값/IP주소 : 76.76.21.21         │
  │ TTL       : 600                 │
  └─────────────────────────────────┘

  ※ "호스트(Host)" 칸에 반드시 @ 만 입력하세요.
     이건 "도메인 자체(예: sherpamath.com)"를 뜻합니다.

  ※ 이미 A 레코드가 있다면:
     기존 A 레코드의 IP 주소만 76.76.21.21 로 수정하세요.
     중복 추가하면 안 됩니다.

  [확인] 또는 [저장] 클릭


============================================================
■ STEP 5. 두 번째 레코드 추가 (CNAME 레코드)
============================================================

  다시 [+ 레코드 추가] 클릭 후:

  ┌──────────────────────────────────────┐
  │ 타입    : CNAME                      │
  │ 호스트  : www                        │
  │ 값      : cname.vercel-dns.com       │
  │ TTL     : 600                        │
  └──────────────────────────────────────┘

  ※ "호스트(Host)" 칸에 www 라고 입력하세요.
     이건 "www.sherpamath.com" 처럼 www 붙는 주소를 뜻합니다.

  ※ 값(Value) 끝에 점(.) 이 붙어 있어도, 안 붙어 있어도 됩니다.
     (가비아가 자동 처리)

  ※ 마지막 글자가 . 인지 헷갈리면 그대로 두셔도 OK.

  [확인] 또는 [저장] 클릭


============================================================
■ STEP 6. 최종 저장 및 확인
============================================================

  1) 화면 하단 또는 우측의 [저장] / [적용] 버튼 클릭

  2) "DNS 정보가 저장되었습니다" 메시지 확인

  3) 표 안에 두 레코드가 잘 들어갔는지 확인:

     ┌────────┬────────┬──────────────────────┐
     │ 타입   │ 호스트 │  값                  │
     ├────────┼────────┼──────────────────────┤
     │ A      │  @     │ 76.76.21.21          │ ← 새로 추가
     │ CNAME  │  www   │ cname.vercel-dns.com │ ← 새로 추가
     │ NS     │  @     │ ns.gabia.co.kr       │ (원래 있던 것)
     │ ...    │  ...   │ ...                  │ (원래 있던 것)
     └────────┴────────┴──────────────────────┘


============================================================
■ STEP 7. 사이트 접속 확인
============================================================

  설정 직후에는 아직 안 떠도 정상입니다.
  보통 30분 ~ 1시간 후 (최대 24시간) 부터 작동합니다.

  1) 30분 후 인터넷 브라우저 주소창에:
     https://sherpamath.com  (또는 구매하신 도메인)

  2) 셰르파 수학학원 홈페이지가 뜨면 성공!

  3) www 붙은 주소도 같이 확인:
     https://www.sherpamath.com

  ※ 만약 24시간 후에도 안 뜨면:
     - 가비아 DNS 표에서 두 레코드가 그대로 있는지 재확인
     - 카톡으로 가비아 DNS 화면 캡처 보내주세요


============================================================
■ 자주 묻는 질문
============================================================

Q1. "@" 가 뭔가요?
A.  도메인 자체를 가리키는 기호입니다.
    @ = sherpamath.com 자체

Q2. NS, MX, SOA 같은 거 지워도 되나요?
A.  절대 지우지 마세요. 메일 등에 필요합니다.
    A, CNAME 두 개만 추가하면 끝입니다.

Q3. 잘못 입력한 것 같아요. 되돌릴 수 있나요?
A.  네, 언제든 가비아 DNS 화면에 다시 들어가
    잘못된 레코드를 [수정] 또는 [삭제] 가능합니다.

Q4. 사이트가 30분 후에도 안 뜨면?
A.  - PC 브라우저 새로고침 (Ctrl + F5)
    - 다른 브라우저에서 시도 (크롬·엣지 둘 다)
    - 휴대폰 데이터로 접속 (Wi-Fi 끄고)
    그래도 안 되면 카톡으로 알려주세요.

Q5. https로 접속 안 되고 http만 되는데요?
A.  Vercel이 자동으로 SSL 인증서 발급합니다.
    DNS 설정 후 5~10분 더 기다리면 https 작동합니다.

Q6. 휴대폰에서도 잘 떠야 하나요?
A.  네, 자동으로 모바일 최적화됩니다.
    PC와 모바일 둘 다 같은 도메인으로 접속하면 됩니다.


============================================================
■ 마지막 체크리스트
============================================================

  □ 가비아에서 도메인 구매 완료
  □ A 레코드 추가 (호스트 @, 값 76.76.21.21)
  □ CNAME 레코드 추가 (호스트 www, 값 cname.vercel-dns.com)
  □ DNS 설정 저장 완료
  □ 30분 ~ 1시간 대기
  □ https://sherpamath.com 접속 확인
  □ https://www.sherpamath.com 접속 확인

전부 체크되면 도메인 연결 완료입니다 🎉
